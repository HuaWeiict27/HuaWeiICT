## 二、赛题2的能力要求拆解

官方把“智能体开发 + MCP/Skills 插件开发”列为独立方向，意味着赛题2不是“调用一次大模型 API”，而是要交付一个可运行、可评估、可解释的 Agent 系统。至少要覆盖：

1. **真实需求与场景定义**：目标用户、痛点、现有替代方案、量化价值。
2. **Agent 架构设计**：单 Agent / 多 Agent、规划、工具调用、记忆、知识库、人机协同、异常兜底。
3. **华为云 AgentArts 平台实现**：Agent 编排、提示词/角色配置、工作流、知识库、插件/Skill、MCP、调试与发布。
4. **数据与知识工程**：数据来源、清洗、切分、向量化、检索、评测集。
5. **工程交付**：代码仓库、配置说明、一键复现、接口文档、单元测试、日志与可观测性。
6. **产品与商业闭环**：用户流程、成本、部署、隐私合规、商业落地路径。
7. **答辩表达**：问题—方案—验证—创新—价值—风险，现场可演示、可复现。

### 赛题2

**基于华为云 AgentArts 智能体开发平台的 Agent 设计和应用**

### 应用领域

休闲娱乐、办公助手、行业应用、生活服务等场景不限。鼓励发掘真实业务痛点，打造具备落地潜力的智能体解决方案。典型方向包括但不限于：

- **行业赋能型**：针对医疗、教育、金融、制造、农业等行业的智能化解决方案。
- **效率提升型**：办公自动化、智能客服、数据分析、文档处理等提效工具。
- **创新探索型**：多 Agent 协同、自主决策、MCP 工具调用、持续学习等前沿技术应用。
- **生活服务型**：健康管理、出行规划、学习辅助、智能家居等生活场景应用。

### 任务要求

- 基于华为云 AgentArts 平台完成智能体的构建、编排与部署。
- 通过可视化 Demo 页面展示核心功能与交互流程。
- 应体现 AgentArts 在智能体设计、工具编排、知识接入、多 Agent 协作、效果评估等环节的使用价值。
- 鼓励形成“场景识别 → Agent 架构设计 → 技能编排 → 调试优化 → 部署上线”的完整闭环高效开发实践。

### 开发工具

- 华为云智果（AgentArts）智能体平台。

### 云服务资源

- 华为云 MaaS 服务 Token Plan 套餐代金券，支持参赛团队调用大模型能力。
- 限定云服务的云资源代金券，助力作品完成云端部署与在线演示。
