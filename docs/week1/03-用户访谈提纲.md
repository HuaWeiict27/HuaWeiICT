# 用户访谈提纲（10—15 分钟）

## 开场

“我们在做一个华为 ICT 大赛的 Agent 项目，想了解你真实的使用经历，没有标准答案，也不会收集你的隐私信息。”

## 1. 背景

1. 你目前在什么场景下会接触这个问题？
2. 你大概多久遇到一次？
3. 最近一次遇到是什么时候？当时发生了什么？

## 2. 现状与替代方案

4. 你现在怎么解决？
5. 用了哪些工具、网站、App、老师或朋友？
6. 哪一步最麻烦、最耗时、最容易出错？
7. 你对现有方案最不满意的是什么？

## 3. 价值与优先级

8. 如果只能改善一个环节，你最希望改哪里？
9. 你愿意为这个改善付出多少时间或费用？
10. 如果有一个智能助手，你最希望它先做什么？

## 4. Agent 接受度

11. 你希望它自动完成，还是每一步都要你确认？
12. 你担心它给出错误建议吗？最担心什么风险？
13. 你希望它用什么方式输出：文字、语音、图片、表格、报告？

## 5. 收尾

14. 如果我们做出 Demo，你愿意试用并给反馈吗？
15. 你身边还有谁经常遇到这个问题？
