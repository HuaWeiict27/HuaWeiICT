# 赛题2教育方向选题库

## 一、教育选题的判断标准

教育方向容易做成“套壳问答”或“搜题工具”，这类项目通常缺乏创新性，还可能有学术诚信风险。优先选择：

1. **教师/学生真实高频痛点**，不是伪需求。
2. **必须用 Agent**：需要规划、追问、工具调用、知识检索、评测或多 Agent。
3. **不直接给答案**：优先做启发式辅导、过程评价、实验安全、教师减负。
4. **数据可得**：教材、课程标准、公开题库、实验手册、模拟班级数据。
5. **可演示**：现场 3—5 分钟能看懂输入、推理、工具调用和结果。
6. **合规**：未成年人隐私、成绩数据、心理健康、医疗诊断均需谨慎。
7. **有商业闭环**：学校、职教、培训机构、企业培训、教育硬件厂商。

## 四、优先推荐：三个最适合你们团队的方向

### 推荐一：实验课智能助教 Agent（首选）

**项目名建议**：LabMate / 实验搭子 / 电路助教

**场景**

大学实验课里，学生接错线、示波器波形不对、代码跑不通、实验报告不会写。老师一个人要带几十个学生，很难逐个排查。学生拍照上传接线、电路图、波形或代码，Agent 用启发式方式引导排查，而不是直接报答案。

**目标用户**

- 电子信息、微电子、自动化、物理等专业的实验课学生
- 实验课教师和助教
- 职业院校实训学生
- 虚拟仿真实验平台厂商

**Agent 设计**

- 视觉识别 Agent：识别元件、接线、波形、错误码。
- 实验知识 Agent：查实验指导书、器件手册、示波器手册。
- 排障 Agent：按故障树逐步追问，给下一步检查建议。
- 安全审核 Agent：识别高压、短路、反接、发热等风险，必要时阻止。
- 报告助教 Agent：根据实验记录生成报告结构和数据解释，但不代写结论。

**工具/Skill/MCP**

- 实验手册 RAG
- 元器件识别工具
- 波形/图像识别工具
- 网表或接线规则校验工具
- 故障树 Skill
- 示波器/开发板模拟数据接口
- 实验报告模板生成工具

**为什么最适合你们**

- 教育场景真实，老师一听就懂。
- 微电子同学可以负责器件、波形、接线、故障树、安全规则，贡献不可替代。
- 软件同学可以负责 Agent 编排、RAG、工具调用、前端和评测。
- 演示效果强：上传一张错误接线图或异常波形，Agent 连续追问并给出排查路径。
- 容易做消融实验：无知识库 vs 有知识库、单 Agent vs 多 Agent。

**2个月MVP**

- 选 3 个实验：Arduino 点亮 LED、基础放大电路、数字逻辑门。
- 每类 20 个故障案例，共 60 条测试集。
- 跑通“拍照/输入现象 → 识别 → 追问 → 排障提示 → 安全审核 → 实验报告提纲”。

**评估指标**

- 故障定位准确率
- 首次提示命中率
- 危险操作拦截率
- 学生独立解决率
- 教师答疑时间节省

**商业价值**

- 高校实验课 SaaS
- 职业院校实训平台
- 虚拟仿真实验厂商
- 教育硬件/开发板厂商配套服务

**风险与边界**

- 不指导高压、带电拆机、危险化学品操作。
- 不代替教师评分，只做过程辅助。
- 所有建议标注“需教师确认”。

### 推荐二：教师备课与分层作业 Agent

**项目名建议**：备课搭子 / 教师Copilot

**场景**

老师备一节课要查课标、做课件、出题、分层作业、写评分标准，还要回复家长。教师上传教材和课标，Agent 生成教案、课堂活动、三层作业、评分量表和家长通知，教师审核后使用。

**Agent 设计**

- 课标 Agent：对齐课程标准和知识点。
- 学情 Agent：根据匿名化学情生成分层任务。
- 出题 Agent：生成基础/提升/挑战三层题目和解析。
- 评价 Agent：生成评分量表并检查题目质量。
- 沟通 Agent：生成家长通知和常见问题答复。

**工具/Skill/MCP**

- 教材/课标知识库
- 题库检索
- 文档导出
- 学习管理系统接口
- 教师审核工作流
- 内容安全检查

**优势**

- 2个月最容易完成。
- 教师付费意愿明确。
- 数据可以用公开教材 + 自建题库，不依赖学生隐私数据。
- 演示直观：上传教材 → 生成教案 → 分层作业 → 评分量表。

**MVP**

- 只选 1 个学科、1 个单元、3 个层次。
- 50 道题、10 份教案、3 份评分量表。
- 对比“无课标RAG”和“有课标RAG”的知识点覆盖率。

**商业模式**

- 学校/培训机构教师 SaaS
- 教育资源平台
- 教育硬件厂商内容服务

**风险**

- 生成内容可能有知识错误，必须教师审核。
- 学生数据必须匿名化，遵守隐私合规。

### 推荐三：职业技能陪练 Agent

**项目名建议**：JobCoach / 实训陪练 / 面试教练

**场景**

学生学了很多理论，但不会面试、不会和客户沟通、不会处理设备故障。Agent 模拟真实工作场景，用户扮演员工，Agent 扮演客户/主管/面试官，结束后给出评分和改进建议。

**Agent 设计**

- 场景导演 Agent：生成任务和突发事件。
- 角色扮演 Agent：扮演客户、主管、面试官。
- 评分 Agent：按岗位胜任力评分。
- 教练 Agent：给出改进建议和下一轮任务。
- 安全 Agent：避免歧视性、违规或高压问题。

**微电子发挥点**

- 电子设备维修陪练
- 产线故障排查陪练
- 元器件识别与焊接安全陪练
- 硬件测试流程考核

**MVP**

- 选 1 个岗位：电子设备维修技术员。
- 5 个场景：客户接待、故障询问、排查、报价、交付。
- 1 套评分量表，20 条测试用例。
- 现场演示：用户与 Agent 角色扮演，结束后生成能力雷达图。

**商业模式**

- 职业院校实训
- 企业新员工培训
- 招聘平台面试陪练
- 培训机构技能认证

**风险**

- 评分必须可解释，不能黑箱。
- 避免把性格、性别、籍贯等无关因素纳入评分。

## 五、备选方向

### 错题诊断与学习路径 Agent

适合做大用户量，但要明确“不直接给答案”。流程应为：学生先写思路 → Agent 追问 → 定位错因 → 给最小提示 → 生成同类题 → 安排复习。

### 科学探究导师 Agent

把孩子的“为什么”变成可操作的家庭小实验，适合做亲子市场和科学教育，但必须有安全审核和年龄适配。

### 无障碍学习助手 Agent

为视障、阅读障碍学生提供易读版、语音版、图解版材料，社会价值高，但多模态和合规要求更高。

### 课堂实时问答助教 Agent

学生匿名提问，Agent 基于老师上传的课件回答，并汇总班级共同困惑点。数据可控，但商业壁垒偏低。

## 六、标题建议

- LabMate：实验课智能助教
- 备课搭子：教师分层教学 Copilot
- JobCoach：职业技能陪练智能体
- 错因侦探：不直接给答案的学习教练
- 好奇实验室：家庭科学探究导师

## 七、最终建议

- **首选**：实验课智能助教 Agent
- **高完成度备选**：教师备课与分层作业 Agent
- **商业化备选**：职业技能陪练 Agent
- **大用户备选**：错题诊断与学习路径 Agent
- **差异化备选**：科学探究导师 Agent

如果你们想同时体现“教育真实痛点、AgentArts 多 Agent/RAG/工具调用、微电子专业优势、现场演示效果”，首选 **实验课智能助教 Agent**。
